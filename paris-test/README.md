# 巴黎临时测试街

这是一份临时测试街，用来试玩已通过的伊娜、巴斯蒂安、铁面人高清帧（卢克此前已接好）。测完会删除整个 `paris-test/` 目录。

打开：

https://zhaozhengdao1124-ctrl.github.io/wordpunch/paris-test/hd/?paris=1

不要把它当成正式版。正式高清仍在 `/wordpunch/hd/`。本目录不会改仓库里已有的 `hd/`、`optimize/` 或根目录游戏文件。

街上仍是 20 只小怪：单数波卢克、双数伊娜，第 10 / 20 只巴斯蒂安，街尾是铁面人。玩家输给小怪时不播小怪庆祝；输给铁面人时会按表播他的庆祝。

可选姿势台（不破坏 `?paris=1`）：

- 伊娜：`?inalab=1`
- 巴斯蒂安：`?bastianlab=1`
- 铁面人：`?ironlab=1`

`1–9` 钉动作，`[` `]` 步进，`G` 地面线。对照旧图可加 `&hdchar=0`。
