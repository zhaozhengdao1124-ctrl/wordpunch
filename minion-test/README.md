# 小怪临时测试街

这是一份临时测试街，用来试玩已通过的五只小怪全套高清帧：胡同混混、练功学徒、武馆大师兄、不良少年、相扑力士。测完会删除整个 `minion-test/` 目录。

不要把它当成正式版。正式高清仍在 `/wordpunch/hd/`。本目录不会改仓库里已有的 `hd/`、`optimize/` 或根目录游戏文件。剑道部女生和首尔三只没有加进来（全套还没交回）。

打开：

- 北京街（混混、学徒交替；第 10 / 20 只是大师兄；街尾再打一场大师兄）：[https://zhaozhengdao1124-ctrl.github.io/wordpunch/minion-test/hd/?beijing=1](https://zhaozhengdao1124-ctrl.github.io/wordpunch/minion-test/hd/?beijing=1)
- 东京街（只有不良少年；第 10 / 20 只是相扑；街尾再打一场相扑）：[https://zhaozhengdao1124-ctrl.github.io/wordpunch/minion-test/hd/?tokyo=1](https://zhaozhengdao1124-ctrl.github.io/wordpunch/minion-test/hd/?tokyo=1)

玩家输给这五只时不播小怪庆祝（包里没有庆祝帧）。打败街尾后，苏绫仍按原表播庆祝。
