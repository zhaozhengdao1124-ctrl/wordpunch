## 六项定向要求：目视结论

1. **run / walk 中间脏像素与 run 腾空偏平**：已改进，比 v2 好。  
   walk 中间帧两脚可分开辨认，不再是胯下混成一块；/004 定型精确保持，循环可接。  
   run：/000 对侧双脚着地宽步；/001 离地过渡；**/002 与 /006 为腾空峰值**（standing 129，双脚离线、宽步幅、有浅色鞋底）；/003 /007 回落；/004 定型精确保持。腾空不再是把两脚收到身下的扁饼。  
   **仍弱**：walk 个别中间帧外侧仍有 1–6px 残丝（定型 /004 自己也有类似残柱）；/005–/008 摆动脚偶发略分裂，因为复用了定型已抬起的靴形。run 腾空峰值的后脚沿用定型那只长条滑动靴，后跟略毛；001/003 与 005/007 因步态对称而相近，不是每格手绘的独特中间帧。

2. **mega_charge_b /002→/003 高度跳变**：已改进，比 v2 好。  
   只改 /002、/003。standing 弧线：120, 118, **132**, **144**, 155, 161…（原 128→147 的 19px 台阶改为 118→132→144→155，单步约 11–14px）。定型 /008 保持，顶点 161 在格内，脚底 ≤162。  
   **仍弱**：/001→/002 仍有约 14px 的起跳步，不是完全匀速。收势 /013–016 仍是 v2 拷贝。

3. **grab_and_beatdown 砸地太小**：已改进，比 v2 好。  
   /003 蓄力抬起（standing 122），/004 定型保持（117），**/005 明显下砸**（104）并带调色板内冲击尘，/006 残压（110）再回到 v2 的 /007。  
   **仍弱**：/006→/007 因 /007 未改，仍有 110→117 的 7px 回弹。冲击尘是小块调色板像素，不是手绘尘云。

4. **stunned 中段动作太少**：已改进，比 v2 好。  
   定型 /007 保持。001–006、008–011 有可读的左右晃（约 6px），不再是 1–2px 微颤。  
   **仍弱**：仍是定型姿态的平移/微倾，不是新画的晕眩循环；收势 /012–013 仍是 v2 拷贝。

5. **celebrate 披风块状、intro 中段发糊**：已改进，比 v2 好，属顺手修。  
   celebrate：001–007 只把披风外沿甩开，不再整件加厚印章；/008 定型保持。甩开比 v2 干净，也更克制。

   程序化「空洞计数」不可靠（定型自己就有腿缝/披风褶皱）。目视未发现新的 typ→idle 换体型跳变，故保持 v2 拷贝。v2 已记录的「收势最末两帧略向 idle 轮廓靠」仍然在。
